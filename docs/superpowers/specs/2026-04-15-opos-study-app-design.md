# OPOS C1 Study App — Design Spec
**Date:** 2026-04-15  
**Exam date:** 2026-04-22 (7 days)  
**Target delivery:** 2026-04-18 (Friday) or 2026-04-19 (Saturday)

---

## 1. Overview

A mobile-first web study app for preparing the C1 Informàtica civil service exam at Ajuntament de Maçanet de la Selva. Hosted on an Oracle server, accessed via VPN from mobile. Single user.

The app parses `ApuntsTemari.md` (1324 lines, 20 topics: 5 general + 15 specific) and provides structured study tools aligned with the real exam format defined in `EdicteC1Maçanet.pdf`.

---

## 2. Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Vue 3 + Vite + Tailwind CSS |
| Backend | Python FastAPI |
| Database | SQLite (aiosqlite) |
| AI | Google Gemini Pro (via backend proxy) |
| Canvas/Drawing | Fabric.js |
| Markdown | marked.js + highlight.js |
| Server | Nginx (reverse proxy) on Oracle server |
| Access | HTTPS via VPN from mobile |

---

## 3. Architecture

```
📱 Mobile (VPN)
    │  HTTPS
    ▼
[Nginx :443]
    ├── Serves Vue 3 SPA (built static files)
    └── Proxy /api/* → [FastAPI :8000]
                           ├── Reads ApuntsTemari.md
                           ├── Reads EdicteC1Maçanet.pdf
                           ├── SQLite (opos.db)
                           └── → Google Gemini Pro API
                                 (key stored in .env, never exposed to client)
```

**Key principle:** The Gemini API key never leaves the server. All AI calls go through FastAPI.

## 4. Navigation & Layout

### Mobile-first layout
- **Navbar** (top): hamburger ☰ | "OPOS C1" | active topic name | 🌙/☀️ theme toggle
- **Bottom tab bar** (thumb zone): 📖 Apunts · 🃏 Flash · 🎯 Pràctica · 📊 Progrés
- **Drawer** (overlay, opened by ☰): list of 20 topics with progress indicators

### Theme
- Auto mode (follows system dark/light preference) with manual toggle button
- CSS custom properties for seamless switching

### Drawer — Topic list
- Grouped: "Bloc General" (5) and "Bloc Específic" (15)
- Per-topic progress indicator: ✓ green (>80%) · ◑ yellow (40–80%) · ○ grey (0%)
- Active topic highlighted in blue
- Closes on outside click or topic selection

---

## 5. Tab: 📖 Apunts

### Content rendering
- Parses `ApuntsTemari.md` on the backend, splits into 20 topic sections
- Rendered with `marked.js` + `highlight.js` for code blocks
- Collapsible section index (h2/h3 headings) at the top of each topic

### Annotations — two modes (toggle button)
**Text mode (default):**
- Long-press or select text → color picker (yellow/blue/green) → optional text note
- Highlights and notes saved to SQLite per topic
- Tap a highlight to see/edit the note or remove it

**Draw mode:**
- Fabric.js canvas overlay on top of the rendered text
- Tools: pen (free draw), circle, arrow, eraser, color selector, stroke width
- Canvas state saved as JSON to SQLite per topic
- Toggle button in toolbar: ✏️ Text | 🖊️ Dibuix

Both modes persist independently. Switching modes doesn't erase the other.

---

## 6. Tab: 🃏 Flashcards

- Flip-card animation (question front / answer back)
- Cards generated by Gemini (15 cards/topic): `{terme, definició, exemple}`
- Manual card creation supported
- Leitner spaced repetition: cards in boxes 1–5, promoted/demoted on review
- Per-session: show due cards → user marks "Sabia" / "No sabia" → updates Leitner box
- Cards persist in SQLite

---

## 7. Tab: 🎯 Pràctica

Five exercise modes aligned with the real exam format (base 9.1.2):

### 7.1 Test d'alternativa
- 10 multiple-choice questions (4 options, 1 correct)
- Gemini generates from topic content
- Immediate feedback per question + full summary at end
- Score saved to SQLite, updates topic progress

### 7.2 Preguntes breus
- 5 short-answer questions per session
- User types response in text area
- Gemini evaluates: score 0–10 + explanation + model answer
- Simulates real exam writing format

### 7.3 Supòsit pràctic
- 1 realistic scenario per session (e.g. "Un usuari de l'ajuntament no pot imprimir...")
- User writes full response
- Gemini evaluates: score 0–10 + key points covered + missing points
- Second exercise can be "exposed orally" — app shows evaluation criteria

### 7.4 Connecta conceptes
- Drag-and-drop: match terms ↔ definitions (8–10 pairs)
- Gemini generates pairs from topic
- Animated feedback on correct/incorrect matches

### 7.5 Omple els buits
- Key sentences from topic with important words blanked out
- User fills in blanks
- Auto-corrected with highlighting

All modes save scores to SQLite. Progress per topic = weighted average of all exercise scores.

---

## 8. Tab: 📊 Progrés

- Overall completion % (weighted across 20 topics)
- Bar chart: General bloc vs Específic bloc
- Per-topic breakdown: score per exercise type (test / breus / supòsit)
- **Exam readiness analysis** (Gemini):
  - Reads all topic scores from SQLite
  - Reads PDF gap analysis results
  - Returns: overall % readiness, top 3 topics to review, estimated exam score
  - Badge: "Examen el 22/04 — resten 7 dies"
- History: last 10 test sessions with date and score

---

## 9. PDF Analysis (EdicteC1Maçanet.pdf)

Run once (or manually triggered from Progrés tab):

1. Backend extracts Annex I temari from PDF
2. Compares each topic point against `ApuntsTemari.md` content
3. Gemini returns per-topic JSON: `{cobertura: "completa|parcial|absent", gaps: [...], suggeriments: [...]}`
4. Results stored in SQLite `pdf_analysis` table
5. Shown in Progrés tab as "Cobertura del temari oficial"

---

## 10. Data Model (SQLite)

```sql
-- Topic progress
progress (topic_id, bloc, score_test, score_breus, score_supòsit,
          score_connecta, score_buits, tests_done, last_activity, overall_pct)

-- Text annotations
annotations (id, topic_id, selected_text, color, note, position_hash, created_at)

-- Drawing canvas
drawings (id, topic_id, canvas_json, updated_at)

-- Flashcards
flashcards (id, topic_id, pregunta, resposta, exemple, origin[auto|manual], 
            leitner_box, next_review, created_at)

-- Practice sessions
practice_sessions (id, topic_id, mode[test|breus|supòsit|connecta|buits], 
                   questions_json, answers_json, score, feedback_json, created_at)

-- PDF analysis
pdf_analysis (id, topic_id, cobertura[completa|parcial|absent], 
              gaps_json, suggeriments_json, analyzed_at)

-- Config
config (key, value)  -- gemini_api_key, theme_preference, etc.
```

## 11. API Endpoints (FastAPI)

```
GET  /api/topics                          → 20 topics with progress %
GET  /api/topics/{id}/content             → parsed markdown for topic
GET  /api/topics/{id}/annotations         → text annotations only
POST /api/topics/{id}/annotations         → save text annotation
GET  /api/topics/{id}/drawings            → canvas JSON for topic
POST /api/topics/{id}/drawings            → save canvas JSON

GET  /api/topics/{id}/flashcards          → flashcards for topic
POST /api/topics/{id}/flashcards/generate → Gemini: generate 15 flashcards
POST /api/flashcards/{id}/review          → update Leitner box

POST /api/topics/{id}/practice/test/generate      → Gemini: 10 MC questions
POST /api/topics/{id}/practice/breus/generate     → Gemini: 5 short questions
POST /api/topics/{id}/practice/supòsit/generate   → Gemini: 1 practical case
POST /api/topics/{id}/practice/connecta/generate  → Gemini: 10 term pairs
POST /api/topics/{id}/practice/buits/generate     → Gemini: fill-in-blanks
POST /api/practice/evaluate                        → Gemini: evaluate written answer
POST /api/practice/sessions                        → save completed session + update progress

GET  /api/progress                        → global progress + per-topic breakdown
GET  /api/progress/exam-readiness         → Gemini: readiness analysis for 22/04
POST /api/pdf/analyze                     → run PDF vs notes comparison

GET  /api/config                          → app config (theme, etc.)
POST /api/config                          → save config (API key, theme)
```

## 12. Gemini Prompts

**Test alternativa:**
```
Ets un professor d'oposicions públiques. Genera 10 preguntes tipus test (4 opcions,
1 correcta) sobre el contingut següent. Retorna JSON estricte:
[{pregunta, opcions:{A,B,C,D}, correcta, explicació}]
CONTINGUT: {topic_text}
```

**Preguntes breus:**
```
Genera 5 preguntes breus (resposta en 2-4 línies) per a un examen de tècnic C1
d'informàtica d'ajuntament. Format JSON: [{pregunta, resposta_model, criteris}]
CONTINGUT: {topic_text}
```

**Supòsit pràctic:**
```
Genera un supòsit pràctic realista per a un tècnic C1 d'informàtica en un ajuntament
petit, basat en el tema: {topic_name}. Ha de requerir aplicació raonada, no memorització.
JSON: {enunciat, context, punts_clau_resposta[], criteri_correccio, dificultat}
```

**Avaluació de resposta:**
```
Avalua aquesta resposta per a la pregunta donada. Puntua de 0 a 10.
PREGUNTA: {pregunta}
RESPOSTA USUARI: {resposta}
RESPOSTA MODEL: {resposta_model}
JSON: {puntuació, encerts[], mancances[], feedback, puntuació_justificada}
```

**Exam readiness:**
```
L'examen és el 22/04/2026. Avui és {data}. Resten {dies} dies.
Progrés per tema: {json_progress}. Gaps del temari oficial: {json_gaps}.
Dona una valoració realista (JSON): {readiness_pct, nota_estimada, temes_prioritaris[3],
consell_estudi, temps_recomanat_per_tema[]}
```

## 13. Deployment

```
Oracle Server
├── /var/www/opos/          → Vue 3 built files (served by Nginx)
├── /opt/opos-api/          → FastAPI app
│   ├── main.py
│   ├── .env                → GEMINI_API_KEY=...
│   └── opos.db             → SQLite database
├── Nginx config            → HTTPS :443, proxy /api/ → :8000
└── systemd service         → FastAPI runs on boot
```

Nginx serves the Vue SPA for all non-`/api` routes (SPA fallback). FastAPI handles all `/api/*` routes.
